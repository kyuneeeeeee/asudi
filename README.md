# 설비 문의 관리

안산도시개발(주) 고객지원팀 설비과가 열사용자 지구의 설비 문의를 접수하고 답변 완료까지 관리하는 웹 앱입니다. 팀원들은 같은 목록에서 어느 지구에 어떤 문의가 들어왔는지, 긴급한 건은 무엇인지, 언제 답변을 마쳤는지 확인할 수 있습니다.

## 문의 한 건의 처리 흐름

안산 지구에서 난방 문의가 들어왔다면 다음과 같이 처리합니다.

1. **접수하기** · 로그인한 뒤 **문의 등록**에서 고객 정보와 문의 내용을 입력합니다. 지구는 ‘안산’, 분류는 ‘난방’으로 선택하고, 빠른 대응이 필요하면 ‘긴급 문의로 표시’를 켭니다.
2. **처리 시작하기** · **문의 목록**에서 ‘난방’과 ‘미처리’로 목록을 좁힙니다. 대응을 시작한 문의의 상태를 ‘처리 중’으로 바꾸면 동료도 진행 상황을 확인할 수 있습니다.
3. **답변 마치기** · 고객에게 답변한 뒤 상태를 ‘답변 완료’로 바꿉니다. 해당 문의는 **처리함**으로 이동하며, 접수 시각과 처리 시각이 함께 표시됩니다.

## 화면 안내

| 메뉴 | 할 수 있는 일 |
| --- | --- |
| **문의 등록** | 고객명·연락처, 접수자, 지구, 설비 분류, 접수 일시와 내용을 기록하고 긴급 여부를 표시합니다. |
| **문의 목록** | 미처리·처리 중인 문의를 분류와 상태로 걸러 보고, 문의별 처리 상태를 변경합니다. |
| **처리함** | 답변을 마친 문의의 내용과 처리 시각을 확인합니다. |
| **삭제함** | 삭제 확인을 거쳐 이동한 문의와 삭제 시각을 확인합니다. |

## 로컬에서 열기

Python이 설치되어 있다면 저장소 루트에서 아래 명령으로 정적 서버를 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 [문의 관리 화면](http://localhost:8000/Index.html)을 열고 이메일과 비밀번호로 로그인합니다. 문의 조회와 저장에는 프로젝트에 연결된 Supabase와 사용자 계정이 필요합니다.

## 구현과 문서
